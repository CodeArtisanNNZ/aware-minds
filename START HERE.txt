AWARE MINDS DEVELOPER HUB 0.7.0

INSTALL
1. Extract the entire ZIP to a permanent folder.
2. Double-click "Install Aware Minds.cmd".
3. If Windows installs missing tools, close the installer and run it once more.
4. Double-click the Aware Minds desktop shortcut.

The ZIP contains no projects or workspace database. A first-time install opens empty.
To deliberately reset an existing installation, double-click "Start Fresh.cmd". Your current workspace is moved to a timestamped backup instead of being deleted.

Aware Minds opens in your default browser. There is no account or sign-in.

ADD A PROJECT
1. Click Add project.
2. Enter a name and either a GitHub repository URL or local Git folder.
3. Open Connections. Choose the folder that contains .git, or choose a destination and Clone.
4. Follow the clickable Connect > Edit > Review > Push bar.
5. Preview every save and push before confirming it.

GitHub may ask you to sign in through Git Credential Manager. Aware Minds never stores your GitHub password. Protected secret files are blocked from Quick Push.
