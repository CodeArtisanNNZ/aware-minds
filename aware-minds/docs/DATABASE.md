# Database and backups

SQLite schema v1 plus repeatable additive v2 upgrade. Tables include users, hashed sessions, application profiles, app key hashes/scopes, conversations, messages, memories, documents, projects, prompts, settings, feedback, usage and audit events. Indexes cover owner/app queries, messages by conversation/time, keys by hash, session expiry and login attempts. Foreign keys are enabled on each connection; older v2-added tables lack full FK/cascade constraints, so formal v3 migrations are pending. Deleting a conversation explicitly deletes its messages; project deletion leaves its conversations. Back up with `python scripts/backup.py`; treat database backups as sensitive. Restore utility is dry-run by default and creates a pre-restore backup on confirmation while API is stopped. User export excludes auth secrets.
