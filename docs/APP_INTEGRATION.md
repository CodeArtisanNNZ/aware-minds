# Server-side integration

From `/developers`, register an app and create a key with only required scopes. Keep the returned key on your **server**; plaintext appears once. Call `POST /api/v1/integrations/{app_id}/chat` with `Authorization: Bearer am_...` and JSON `{"app_id":"your-app","message":"Hello"}`. The response includes message/model/conversation/source metadata; only Ollama is supported. Memory search needs `memory.read`. A revoked key fails immediately. Tested contracts exist for `packages/js-sdk` and `packages/python-sdk`; examples for Next.js/Bujhi, PHP/Healthcare Central, Python/KAL.RA and JS/Kishan Bari live under `examples/`. PHP runtime was unavailable for this QA pass. **A key identifies an app-owner service account, never an individual patient/student.** Do not connect private external user accounts until delegated end-user identity exists.
